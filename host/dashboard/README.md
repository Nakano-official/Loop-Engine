# Loop Engine のダッシュボード

ホストで動く Web の画面です。この PC にある**全部のアプリ**（`apps/`）について、通しの進み具合、
落ちた場所と戻り先、出力されたアプリを見せ、遊んで承認・差し戻しを記録し、通しを始めたり止めたりします。
表示するものは全部 `engine/apps.py` から読み、ダッシュボード自身は状態を持ちません。

## 起動

```powershell
host\loop-dashboard.cmd          # http://127.0.0.1:8443
```

アプリの置き場は既定で、このリポジトリの隣の `apps\`（`--apps` で変えられる）。
アプリを作るのは今はコマンドから: `python engine\cli.py new <名前> --title ... --definition ... --design ...`。

## できること

| | この PC から | 遠隔（tailnet） |
|---|---|---|
| アプリ・通し・モジュールごとの状態と判定を見る | ○ | ○ |
| 出力されたアプリを開いて遊ぶ | ○ | ○ |
| **差し戻す**、走っている通しを**止める** | ○ | ○ |
| **承認する** | ○ | × |
| 通しを**始める** | ○ | × |
| 箱の状態（窓口・モデル・通信制限・空き容量）を見る | ○ | ○ |

**「駄目だ」は安く、「良い」は高い。** 承認は、アプリを実際に遊べる場所でしかできない。画面を見られない端末が
「遊べた」と記録できたら、人間に訊く関門そのものが無意味になる（`engine/apps.py` も遠隔の承認を拒む）。
通しを始めるのも、その結果を遊ぶ人がいるこの PC から。止めるのはどこからでもできる。

通しは**全部のアプリを通して同時に1つだけ**。箱の solver の置き場が1つなので（`engine/apps.py` のロック）。

## 設計上の境界

- **常に `127.0.0.1` だけで待ち受ける。** 外から見えるようにするのは `tailscale serve` の仕事で、
  このサーバは LAN にも一度も出ない
- `Host` ヘッダが**応答してよい名前の一覧**（ループバック＋公開名）に無ければ拒否する。ループバック束縛と
  CORS だけでは DNS リバインディングを防げない。リバインドされた要求が偽装できない唯一の値が `Host`
- 公開名で来た要求は、`tailscale serve` が書く `Tailscale-User-Login` が `config.json` の名簿にある場合だけ
  通す。このヘッダが意味を持つのは Host が先に一致したからで、順序が逆なら何の保証も無い
- 状態を変える API はセッショントークンを要求する
- **出力されたアプリは、モデルが書いたコードである。** `Content-Security-Policy: sandbox allow-scripts;
  default-src 'none'` を付けて返し、画面では `sandbox="allow-scripts"` の iframe に入れる。どこで開いても
  不透明なオリジンになり、ダッシュボードの API もトークンも読めず、外へ通信もできない。そのため保存
  （localStorage）は効かない ── ここは遊んで確かめるための表示
- 判断の記録は**追記のみ**（`apps/<名前>/decisions.jsonl`）。記録には `scope` と `user` が入る。
  **どこから答えたかは答えの一部**
- HTTP の値をコマンドラインに展開しない。通しを始めるときに要求から使うのは、既にあるアプリの名前だけ
  （`shell=False`）

## 遠隔から見る

`config.json` に公開名と名簿を書く。**両方書いて初めて公開**で、`remote` が無い、あるいは `users` が空なら
「全員に公開」ではなく**誰にも公開しない**（fail closed）。

```json
"remote": {
  "host": "<machine>.<tailnet>.ts.net:8443",
  "users": ["you@example.com"]
}
```

`users` に書くのは Tailscale のログイン。`tailscale serve` はクライアントが送った
`Tailscale-User-Login` を**上書き**するので、tailnet の外から詐称はできない。
**`tailscale funnel` は使わないこと。** あれはインターネット全体への公開である。
