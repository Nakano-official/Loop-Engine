# アイドルゲーム完成要件

- Windows 上で画面を起動し、プレイヤーが操作できるアイドルゲームであること。
- ゲーム中は時間の経過に応じて資源が増え、現在の資源量と毎秒の生産量を画面で確認できること。
- プレイヤーが複数種類のジェネレーターを購入でき、それぞれの価格、所持数、生産量を確認できること。
- ゲームを終了して再起動しても状態が復元され、閉じていた時間に応じた生産が反映されること。
- プレイヤーが確認操作をしたうえでセーブデータを消去し、最初からやり直せること。
- 既存のシミュレーション核を利用し、その既存テストをすべて保ったまま完成させること。
- README に、必要な環境、起動方法、保存場所、基本操作が記載され、その手順だけで起動できること。
- 機械的な受け入れ条件がすべて Green になった時点で予定プレイテストとして停止し、オペレーターGUIから成果物を起動して人間が承認または修正依頼を記録できること。
