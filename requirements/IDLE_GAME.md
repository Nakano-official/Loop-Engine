# アイドルゲーム完成要件

- リポジトリのルートで `python -m idlegame` と打つだけで Windows 上に画面が開き、
  プレイヤーが操作できるアイドルゲームであること。**ディレクトリの移動や環境変数の
  設定を必要としないこと。**
- **新規開始した直後から遊べること。** 開始直後の画面にプレイヤーが押せる操作が
  必ず一つ以上あり、**その操作だけを繰り返すことで最初のジェネレーターを購入できる
  ところまで到達できること。** 何も購入していない状態で操作可能なものが無い、
  という状態が存在しないこと。
- プレイヤーの手動操作で資源を増やせること。
- ジェネレーターを所持している間は時間の経過に応じて資源が増え、現在の資源量と
  毎秒の生産量を画面で確認できること。
- プレイヤーが複数種類のジェネレーターを購入でき、それぞれの価格、所持数、生産量を
  画面で確認できること。
- ゲームを終了して再起動しても状態が復元され、閉じていた時間に応じた生産が
  反映されること。
- プレイヤーが**画面上の操作で**、確認操作をしたうえでセーブデータを消去し、
  最初からやり直せること。消去の機能が内部に存在するだけでは足りず、
  **開いている画面から実行できること。**
